# Testing Plan

## Individual YOLO Testing

- Report precision, recall, mAP@0.5, mAP@0.5:0.95, and confusion matrix for each member model.
- Include example true positives, false positives, and false negatives.

## Meta-Classifier Testing

- Report accuracy, precision, recall, F1-score, and confusion matrix.
- Compare the meta-classifier result with at least one individual YOLO model.
- Provide at least five examples where overlapping or conflicting predictions are resolved.

## Mobile App Testing

Test with:

- Live camera inference.
- Recorded video.
- Controlled real-time demonstration.

Record:

- Latency.
- False detections.
- Missed detections.
- Lighting sensitivity.
- Usability observations.
